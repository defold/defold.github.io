# Огляд редактора {#editor-overview}

Редактор дає змогу зручно переглядати всі файли й папки ігрового проєкту та працювати з ними. Коли ви відкриваєте файл для редагування, з’являється відповідний редактор, а вся пов’язана з файлом інформація відображається в окремих панелях.

## Запуск редактора {#starting-the-editor}

Коли ви запускаєте редактор Defold, з’являється екран вибору та створення проєктів. Натисніть, щоб вибрати потрібну дію:

MY PROJECTS
: Тут містяться нещодавно відкриті проєкти для швидкого доступу до них. Це стандартна вкладка початкового екрана.

  Якщо ви ще не відкривали проєктів (або видалили всі), тут відображатимуться дві кнопки: натисніть `Open From Disk…`, щоб знайти й відкрити проєкт за допомогою системного файлового менеджера, або `Create New Project`, щоб перейти на вкладку `TEMPLATES`.

  ![Мої проєкти](/manuals/images/editor/start_no_projects.png)


  Якщо ви вже відкривали проєкти, тут відображатиметься їхній список, як на зображенні нижче:

  ![Мої проєкти](/manuals/images/editor/start_my_projects.png)

TEMPLATES
: Містить порожні або майже порожні базові проєкти для швидкого початку нового проєкту Defold для певних платформ або з певними розширеннями.


TUTORIALS
: Містить проєкти з покроковими уроками, які можна вивчати, запускати та змінювати, якщо ви хочете пройти урок.


SAMPLES
: Містить проєкти, підготовлені для демонстрації певних способів використання.

  ![Новий проєкт](/manuals/images/editor/start_templates.png)

Коли ви створюєте новий проєкт, він зберігається на локальному диску, і всі внесені зміни також зберігаються локально.

Докладніше про різні варіанти читайте в [посібнику з налаштування проєкту](https://www.defold.com/uk/manuals/project-setup/).

## Мова редактора {#editor-language}

У нижньому лівому куті початкового екрана є вибір мови: виберіть одну з доступних локалізацій. У редакторі цей параметр також доступний у `File ▸ Preferences ▸ General ▸ Editor Language`.

![Мови](/manuals/images/editor/languages.png)

## Панелі редактора {#the-editor-views}

Редактор Defold поділено на панелі, або області перегляду, кожна з яких відображає певну інформацію.

![Редактор 2](/manuals/images/editor/editor_overview.png)

### 1. Панель Assets {#1-assets-pane}
Містить усі файли й папки проєкту в деревоподібній структурі, що відповідає структурі на диску. Натискайте елементи й прокручуйте список для навігації. Усі операції з файлами можна виконувати на цій панелі:

   - <kbd>Натисніть лівою кнопкою миші</kbd>, щоб вибрати файл або папку. Утримуючи <kbd>⇧ Shift</kbd>, можна розширити вибір, а утримуючи <kbd>Ctrl</kbd>/<kbd>⌘ Cmd</kbd> — додати натиснутий елемент до вибраних або скасувати його вибір.
   - <kbd>Двічі натисніть мишею</kbd> файл, щоб відкрити його в редакторі для цього типу файлів.
   - <kbd>Перетягніть</kbd> файли з іншого місця на диску, щоб додати їх до проєкту, або перетягніть файли й папки, щоб перемістити їх у нове місце в проєкті.
   - <kbd>Натисніть правою кнопкою миші</kbd>, щоб відкрити _контекстне меню_, у якому можна створювати файли й папки, перейменовувати та видаляти їх, відстежувати залежності файлів тощо.

Файли й папки, видалені через панель *Assets*, переміщуються до системного кошика, якщо платформа це підтримує. Якщо переміщення до кошика не підтримується або не вдається, редактор видаляє їх безповоротно.

### 2. Панель Scene Editor {#the-scene-editor}

Подвійне натискання файлу колекції (collection), ігрового об’єкта (game object) або візуального компонента (component) відкриває *Scene Editor* — візуальний редактор для створення та редагування сцен. Файли скриптів та інші невізуальні ресурси відкриваються у власних спеціалізованих редакторах.

![Редактор сцени](/manuals/images/editor/2d_scene.png)

Основні можливості редактора сцени:

- [Навігація у 2D- і 3D-сценах](/uk/manuals/scene-editing/#2d-and-3d-scene-orientation) з ортографічним і перспективним режимами камери
- [Інструменти трансформації](/uk/manuals/scene-editing/#manipulating-objects) для переміщення, повороту та масштабування об’єктів
- [Режим вільної камери](/uk/manuals/scene-editing/#free-camera-mode) для навігації у 3D від першої особи
- [Налаштування сітки](/uk/manuals/scene-editing/#grid-settings) зі змінюваними розміром, площиною та виглядом
- [Фільтри видимості](/uk/manuals/scene-editing/#visibility-filters) для перемикання відображення типів компонентів і напрямних

Докладніше читайте в [посібнику з редактора сцени](/uk/manuals/scene-editing/).

### 3. Панель Outline {#3-outline-pane}

Ця панель показує вміст редагованого файлу як ієрархічне дерево. Вміст Outline відповідає області редактора й дає змогу виконувати операції з елементами:

   - <kbd>Натисніть лівою кнопкою миші</kbd>, щоб вибрати елемент. Утримуючи <kbd>⇧ Shift</kbd>, можна розширити вибір, а утримуючи <kbd>Ctrl</kbd>/<kbd>⌘ Cmd</kbd> — додати натиснутий елемент до вибраних або скасувати його вибір.
   - <kbd>Перетягніть</kbd> елементи, щоб перемістити їх. Перетягніть ігровий об’єкт на інший ігровий об’єкт у колекції, щоб створити батьківсько-дочірній зв’язок.
   - <kbd>Натисніть правою кнопкою миші</kbd>, щоб відкрити _контекстне меню_, у якому можна додавати елементи, видаляти вибрані елементи тощо.

Видимість ігрових об’єктів і візуальних компонентів можна перемикати, натискаючи маленьку піктограму ока `👁` праворуч від елемента в списку.

![Структура](/manuals/images/editor/outline.png)

### 4. Панель Properties {#4-properties-pane}

Ця панель показує властивості вибраного елемента, як-от Id, URL, Position, Rotation, Scale та/або інші властивості, специфічні для компонента, а також користувацькі властивості скриптів.

Також можна <kbd>перетягнути</kbd> стрілку вгору-вниз `↕` і рухати мишу, щоб змінити значення відповідної числової властивості.

![Властивості](/manuals/images/editor/properties.png)

### 5. Панель Tools {#5-tools-pane}

Ця панель містить кілька вкладок.

Вкладка *Console* : показує виведення рушія з помилками, попередженнями та інформаційними повідомленнями, а також текст, який ви навмисно виводите під час роботи гри,

*Build Errors* : показує помилки процесу збирання,

*Search Results* : показує результати пошуку (<kbd>Ctrl</kbd>/<kbd>⌘ Cmd</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd>) у всьому проєкті, якщо натиснути `Keep Results`

*Curve Editor* : використовується для редагування кривих у [редакторі частинок](/uk/manuals/particlefx/).

Панель Tools також використовується для роботи з вбудованим налагоджувачем. Докладніше про нього читайте в [посібнику з налагодження](/uk/manuals/debugging/).

### 6. Панель Changed Files {#6-changed-files-pane}

Якщо проєкт використовує Git, ця панель містить файли, які було локально змінено, додано, перейменовано або видалено порівняно з поточним комітом (`HEAD`). Для синхронізації з віддаленим репозиторієм використовуйте зовнішній клієнт Git або командний рядок. Докладніше читайте в [посібнику з контролю версій](/uk/manuals/version-control/). На цій панелі можна виконувати деякі операції з файлами:

   - <kbd>Натисніть лівою кнопкою миші</kbd>, щоб вибрати файл. Утримуючи <kbd>⇧ Shift</kbd>, можна розширити вибір, а утримуючи <kbd>Ctrl</kbd>/<kbd>⌘ Cmd</kbd> — додати натиснутий елемент до вибраних або скасувати його вибір. Якщо вибрано один змінений файл, можна натиснути `Diff`, щоб переглянути відмінності. Натисніть `Revert`, щоб скасувати зміни в усіх вибраних файлах.
   - <kbd>Двічі натисніть лівою кнопкою миші</kbd> файл, щоб відкрити його. Редактор відкриє файл у відповідному редакторі, як і на панелі ресурсів.
   - <kbd>Натисніть правою кнопкою миші</kbd> файл, щоб відкрити спливне меню, у якому можна переглянути відмінності, скасувати всі зміни у файлі, знайти файл у файловій системі тощо.

### Рядок меню {#menu-bar}

Угорі вікна редактора або в системному рядку на Mac міститься рядок із 6 меню: `File`, `Edit`, `View`, `Project`, `Debug`, `Help`. Їхні функції пояснюються в посібниках.

### Рядок стану {#status-bar}

У нижній частині редактора є вузький рядок, у якому відображається стан, наприклад:
- коли з’являється нове оновлення, стає видимою кнопка `Update Available` — див. розділ «Оновлення редактора» нижче в цьому посібнику.
- під час збирання або пакування тут відображається перебіг процесу.

## Розмір і видимість панелей {#panes-size-and-visibility}

Розмір панелей у редакторі можна змінювати, <kbd>перетягуючи</kbd> межі між усіма 6 панелями, описаними вище.

Видимість панелей у редакторі можна перемикати за допомогою пунктів меню `View` або відповідних клавіатурних скорочень:
- `Toggle Assets Pane` (<kbd>F6</kbd>) — перемикає видимість панелей Assets і Changed Files
- `Toggle Changed Files` — перемикає видимість лише панелі Changed Files
- `Toggle Tools Pane` (<kbd>F7</kbd>) — перемикає видимість панелі Tools
- `Toggle Properties Pane` (<kbd>F8</kbd>) — перемикає видимість панелей Outline і Properties

![Видимість панелей](/manuals/images/editor/editor_panes.png)

У меню `View` можна також перемикати або змінювати інші параметри відображення, як-от Grid, Guides, Camera, підлаштовувати область перегляду під вибрані елементи (`Frame Selection` або клавіша <kbd>F</kbd>) і перемикатися між стандартними 2D- і 3D-видами (`Realign Camera` або клавіша <kbd>.</kbd>). Багато з цих функцій також доступні на панелі інструментів або через клавіатурні скорочення.

## Вкладки {#tabs}

Якщо відкрито кілька файлів, для кожного з них угорі області редактора відображається окрема вкладка.  Вкладки в межах однієї панелі можна переміщувати — <kbd>перетягніть</kbd> їх, щоб змінити порядок у рядку вкладок. Також можна:

- <kbd>Натиснути правою кнопкою миші</kbd> вкладку, щоб відкрити _контекстне меню_,
- Натиснути `Close` (<kbd>Ctrl</kbd>/<kbd>⌘ Cmd</kbd> + <kbd>W</kbd>), щоб закрити одну вкладку,
- Натиснути `Close Others`, щоб закрити всі вкладки, крім вибраної,
- Натиснути `Close All` (<kbd>Ctrl</kbd>/<kbd>⌘ Cmd</kbd> + <kbd>Shift</kbd>+<kbd>W</kbd>), щоб закрити всі вкладки активної панелі,
- Вибрати `➝| Open As`, щоб використати інший редактор замість стандартного або пов’язаний зовнішній інструмент, заданий у `File ▸ Preferences ▸ Code ▸ Custom Editor`. Докладніше читайте в [посібнику з налаштувань редактора](/uk/manuals/editor-preferences).

![Вкладки](/manuals/images/editor/tabs_custom.png)

## Редагування у двох панелях поруч {#side-by-side-editing}

Можна відкрити 2 області редактора поруч.

- <kbd>Натисніть правою кнопкою миші</kbd> вкладку редактора, яку хочете перемістити, і виберіть `Move to Other Tab Pane`.

![2 панелі](/manuals/images/editor/2-panes.png)

Також у меню вкладки можна вибрати `Swap with Other Tab Pane`, щоб перемістити її між панелями, або `Join Tab Panes`, щоб об’єднати панелі в одну.

## Створення файлів проєкту {#creating-new-project-files}

Щоб створити файл ресурсу, виберіть `File ▸ New…`, а потім тип файлу в меню, або скористайтеся контекстним меню:

<kbd>Натисніть правою кнопкою миші</kbd> потрібне місце на панелі `Assets`, а потім виберіть `New… ▸ [file type]`:

![Створення файлу](/manuals/images/editor/create_file.png)

Введіть відповідне ім’я нового файлу в полі *Name* і за потреби змініть *Location*. Повне ім’я файлу з розширенням типу файлу відображається в полі *Preview* діалогового вікна:

![Ім’я створюваного файлу](/manuals/images/editor/create_file_name.png)

## Шаблони {#templates}

Для кожного проєкту можна задати власні шаблони. Для цього створіть папку `templates` у кореневому каталозі проєкту й додайте файли з іменами `default.*` та потрібними розширеннями, наприклад `/templates/default.gui` або `/templates/default.script`. Крім того, якщо в цих файлах використано маркер `{% raw %}{{NAME}}{% endraw %}`, його буде замінено на ім’я файлу, задане у вікні створення файлу.

Якщо для певного типу файлів є шаблон, кожен новий файл цього типу заповнюватиметься вмістом відповідного файлу з `templates`.


![Шаблони](/manuals/images/editor/templates.png)

## Імпортування файлів до проєкту {#importing-files-to-your-project}

Щоб додати файли ресурсів (зображення, звуки, моделі тощо) до проєкту, просто перетягніть їх у потрібне місце на панелі *Assets*. У вибраному місці файлової структури проєкту буде створено _копії_ файлів. Докладніше про [імпортування ресурсів читайте в нашому посібнику](/uk/manuals/importing-assets/).

![Імпортування файлів](/manuals/images/editor/import.png)

## Оновлення редактора {#updating-the-editor}

Редактор автоматично перевіряє наявність оновлень за підключення до інтернету. Коли оновлення знайдено, синє посилання `Update Available` з’являється в нижньому лівому куті екрана вибору проєкту або в нижньому правому куті вікна редактора.

![Оновлення з екрана вибору проєкту](/manuals/images/editor/update_start.png)
![Оновлення з редактора](/manuals/images/editor/update_available.png)

Натисніть посилання `Update Available`, щоб завантажити й установити оновлення. З’явиться вікно підтвердження з інформацією — натисніть `Download Update`, щоб продовжити.

![Вікно оновлення редактора](/manuals/images/editor/update.png)

У нижньому рядку стану відображатиметься перебіг завантаження:

![Перебіг завантаження](/manuals/images/editor/download_status.png)

Після завантаження оновлення синє посилання зміниться на `Restart to Update`. Натисніть його, щоб перезапустити й відкрити оновлений редактор.

![Перезапуск для оновлення](/manuals/images/editor/restart_to_update.png)

## Налаштування {#preferences}

Змінити налаштування редактора можна у вікні `Preferences`. Щоб відкрити його, натисніть `File ▸ Preferences…` або скористайтеся клавіатурним скороченням <kbd>Ctrl</kbd>/<kbd>⌘ Cmd</kbd> + <kbd>,</kbd>

Докладніше читайте в [посібнику з налаштувань редактора](/uk/manuals/editor-preferences)

## Журнали редактора {#editor-logs}
Якщо у вас виникла проблема з редактором і потрібно повідомити про неї (`Help  ▸ Report Issue`), варто додати файли журналів самого редактора. Щоб відкрити папку журналів у системному файловому менеджері, натисніть `Help ▸ Show Logs`.

Докладніше читайте в [посібнику з отримання допомоги](/uk/manuals/getting-help/#getting-help).

![Перегляд журналів](/manuals/images/editor/show_logs.png)

Файли журналів редактора розташовані тут:

  * Windows: `C:\Users\ **Your Username** \AppData\Local\Defold`
  * macOS: `/Users/ **Your Username** /Library/Application Support/` або `~/Library/Application Support/Defold`
  * Linux: `$XDG_STATE_HOME/Defold` або `~/.local/state/Defold`

Також можна переглядати журнали під час роботи редактора, якщо його запущено з термінала або командного рядка. Щоб запустити редактор, використовуйте команду:

```shell
# Linux:
$ ./path/to/Defold/Defold

# macOS:
$ > ./path/to/Defold.app/Contents/MacOS/Defold
```

## Сервер редактора {#editor-server}

Коли редактор відкриває проєкт, він запускає вебсервер на випадковому порту. Цей сервер можна використовувати для взаємодії з редактором з інших застосунків. Порт записується у файл `.internal/editor.port`.

Сервер надає специфікацію OpenAPI за адресою `http://localhost:$(cat .internal/editor.port)/openapi.json`. Це корисна мінімальна відправна точка для робочих процесів із залученням агентів.

Крім того, виконуваний файл редактора має параметр командного рядка `--port` (або `-p`), який дає змогу вказати порт під час запуску, наприклад::
```shell
# Windows
.\path\to\Defold\Defold.exe --port 8181

# Linux:
./path/to/Defold/Defold --port 8181

# macOS:
./path/to/Defold/Defold.app/Contents/MacOS/Defold --port 8181
```

## Метадані встановлення редактора {#editor-installation-metadata}

Під час запуску редактор записує інформацію про програму запуску та шляхи встановлення у визначене місце. Сторонні інтеграції з IDE та інші інструменти можуть використовувати ці дані для пошуку встановлених редакторів Defold:

| ОС      | Розташування |
|---------|----------|
| macOS   | `~/Library/Application Support/Defold/installations.json` |
| Linux   | `${XDG_STATE_HOME:-~/.local/state}/Defold/installations.json` |
| Windows | `%LOCALAPPDATA%\Defold\installations.json` |

Файл містить масив JSON з одним об’єктом для кожного відомого встановлення:

```json
[
  {
    "launcherPath": "/Applications/Defold.app/Contents/MacOS/Defold",
    "installPath": "/Applications/Defold.app",
    "lastLaunchedAt": "2026-07-06T12:34:56.789Z"
  }
]
```
