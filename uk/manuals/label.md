# Текстова мітка {#label}

Компонент (component) *Label* (текстова мітка) відображає фрагмент тексту на екрані в ігровому просторі. За замовчуванням він сортується й відмальовується разом з усією графікою спрайтів і плиток. Компонент має набір властивостей, які визначають спосіб відображення тексту. GUI в Defold підтримує текст, але розміщувати елементи GUI в ігровому світі буває складно. Текстові мітки спрощують це завдання.

## Створення текстової мітки {#creating-a-label}

Щоб створити компонент Label, <kbd>клацніть правою кнопкою миші</kbd> на ігровому об’єкті (game object) і виберіть <kbd>Add Component ▸ Label</kbd>.

![Додавання текстової мітки](/manuals/images/label/add_label.png)

(Якщо ви хочете створити кілька екземплярів (instance) міток за одним шаблоном, можна натомість створити новий файл компонента Label: <kbd>клацніть правою кнопкою миші</kbd> на папці в браузері *Assets* і виберіть <kbd>New... ▸ Label</kbd>, а потім додайте цей файл як компонент до будь-яких ігрових об’єктів)

![Нова текстова мітка](/manuals/images/label/label.png)

У властивості *Font* вкажіть потрібний шрифт і обов’язково встановіть для властивості *Material* матеріал, що відповідає типу шрифту:

![Шрифт і матеріал](/manuals/images/label/font_material.png)

## Властивості текстової мітки {#label-properties}

Окрім властивостей *Id*, *Position*, *Rotation* і *Scale*, компонент має такі специфічні властивості:

*Text*
: Текстовий вміст мітки.

*Size*
: Розмір обмежувальної рамки тексту. Якщо ввімкнено *Line Break*, ширина визначає місце перенесення тексту на новий рядок.

*Color*
: Колір тексту.

*Outline*
: Колір контуру.

*Shadow*
: Колір тіні.

<div class='sidenote' markdown='1'>
Зауважте, що в стандартному матеріалі рендеринг тіні вимкнено задля продуктивності.
</div>

*Leading*
: Коефіцієнт масштабування міжрядкового інтервалу. Значення 0 усуває міжрядковий інтервал. За замовчуванням — 1.

*Tracking*
: Коефіцієнт масштабування міжлітерного інтервалу. За замовчуванням — 0.

*Pivot*
: Опорна точка тексту. Використовуйте її для змінення вирівнювання тексту (див. нижче).

*Blend Mode*
: Режим змішування, який використовується під час рендерингу мітки.

*Line Break*
: Вирівнювання тексту визначається налаштуванням опорної точки, а ввімкнення цієї властивості дає змогу розміщувати текст у кількох рядках. Ширина компонента визначає місце перенесення тексту. Зауважте, що для перенесення в тексті має бути пробіл.

*Font*
: Ресурс шрифту для цієї мітки.

*Material*
: Матеріал для рендерингу цієї мітки. Обов’язково виберіть матеріал, створений для типу шрифту, який ви використовуєте (растровий, на основі поля відстаней або BMFont).

### Опорна точка й вирівнювання {#pivot-and-alignment}

Налаштувавши властивість *Pivot*, ви можете змінити режим вирівнювання тексту.

*По центру*
: Якщо для опорної точки встановлено значення `Center`, `North` або `South`, текст вирівнюється по центру.

*По лівому краю*
: Якщо для опорної точки встановлено будь-який із режимів `West`, текст вирівнюється по лівому краю.

*По правому краю*
: Якщо для опорної точки встановлено будь-який із режимів `East`, текст вирівнюється по правому краю.

![Вирівнювання тексту](/manuals/images/label/align.png)

## Керування під час виконання {#runtime-manipulation}

Ви можете керувати мітками під час виконання, отримуючи й установлюючи текст мітки та різні інші властивості.

`text`
: Текстовий вміст напису (`string`). Доступний через `go.get()` і `go.set()` починаючи з Defold 1.13.2.

`color`
: Колір мітки (`vector4`)

`outline`
: Колір контуру мітки (`vector4`)

`shadow`
: Колір тіні мітки (`vector4`)

`scale`
: Масштаб мітки: `number` для рівномірного масштабування або `vector3` для окремого масштабування вздовж кожної осі.

`size`
: Розмір мітки (`vector3`)

```lua
function init(self)
    -- Set the text of the "my_label" component in the same game object
    -- as this script.
    go.set("#my_label", "text", "New text")
    local text = go.get("#my_label", "text")
    print(text) -- New text
end
```

<div class='sidenote' markdown='1'>
Починаючи з Defold 1.13.2, `label.set_text()` і `label.get_text()` застаріли на користь властивості `text`. Старі функції залишаються доступними для сумісності. Старий засіб установлення тексту ставить повідомлення в чергу, а `go.set()` оновлює текст негайно.
</div>

```lua
function init(self)
    -- Set the color of the "my_label" component in the same game object
    -- as this script. Color is a RGBA value stored in a vector4.
    local grey = vmath.vector4(0.5, 0.5, 0.5, 1.0)
    go.set("#my_label", "color", grey)

    -- ...and remove the outline, by setting its alpha to 0...
    go.set("#my_label", "outline.w", 0)

    -- ...and scale it x2 along x axis.
    local scale_x = go.get("#my_label", "scale.x")
    go.set("#my_label", "scale.x", scale_x * 2)
end
```
