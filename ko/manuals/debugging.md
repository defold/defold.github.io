# 디버깅

Defold에는 검사 기능을 갖춘 통합 Lua 디버거가 있습니다. 내장된 [프로파일링 도구](/ko/manuals/profiling)와 함께 사용하면 게임 로직의 버그 원인을 찾거나 성능 문제를 분석하는 데 도움이 되는 강력한 도구입니다. 또한 엔진 자체가 드물게 크래시되는 경우를 위해 크래시 로그도 제공합니다.

Lua 디버거는 네이티브 디버그 및 헤드리스 빌드에서 사용할 수 있습니다. 릴리스와 웹 빌드는 디버거 연결을 지원하지 않습니다.

* [게임 로직 디버깅](/ko/manuals/debugging-game-logic)에 대해 더 알아보세요.
* [VS Code 설정 예제](/ko/manuals/debugging-game-logic/#vs-code)를 포함한 [외부 디버거 연결 방법](/ko/manuals/debugging-game-logic/#native-dap-connections)을 알아보세요.
* [네이티브 코드 디버깅](/ko/manuals/debugging-native-code)에 대해 더 알아보세요.
* Lua 또는 개발 도구에서 [게임 창을 MP4 파일로 녹화하는 방법](/ko/manuals/recording)을 알아보세요.
