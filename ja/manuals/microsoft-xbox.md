# Xbox のサポート {#xbox-support}

Defold は、まだ Microsoft Xbox をサポートしていません。Defold Foundation は、Xbox のミドルウェアプロバイダーになるために積極的に取り組んでいます。承認済みの Xbox 開発者の皆様には、Xbox 開発者窓口の担当者に連絡し、Defold の Microsoft Xbox 対応を要望することをお勧めします。
