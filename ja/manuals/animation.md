# アニメーション {#animation}

Defold は、コンポーネント（component）のグラフィックスとして利用できる、さまざまな種類のアニメーションを標準でサポートしています。

* [フリップブックアニメーション（flip-book animation）](/ja/manuals/flipbook-animation) - 一連の静止画像を順番に切り替えて再生します。
* [モデルアニメーション（model animation）](/ja/manuals/model-animation) - スキニングを用いた 3D アニメーションを再生します。
* [プロパティアニメーション（property animation）](/ja/manuals/property-animation) - 位置、スケール、回転など、多くのプロパティをアニメーションさせます。

拡張機能（extension）を通じて、さらにアニメーション形式を追加できます。

* [Rive アニメーション](/extension-rive) - ベクトルベースの 2D スケルタルアニメーション（skeletal animation）を再生します。
* [Spine アニメーション](/extension-spine) - テクスチャを使用した 2D スケルタルアニメーションを再生します。
