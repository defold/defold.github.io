# Debug {#debugging}

Defold include un debugger Lua integrato con funzionalità di ispezione. Insieme agli [strumenti di profilazione](/it/manuals/profiling) integrati, è uno strumento potente che può aiutarti a individuare la causa degli errori nella logica del tuo gioco o ad analizzare i problemi di prestazioni. Defold fornisce anche log dei crash per le rare occasioni in cui è il motore stesso ad arrestarsi in modo anomalo.

Il debugger Lua è disponibile nelle build native di debug e headless. Le build di release e Web non supportano il collegamento del debugger.

* Scopri come [collegare un debugger esterno](/it/manuals/debugging-game-logic/#native-dap-connections), compreso un [esempio di configurazione di VS Code](/it/manuals/debugging-game-logic/#vs-code).
* Scopri di più sul [debug del codice nativo](/it/manuals/debugging-native-code).
* Scopri come [registrare la finestra del gioco in un file MP4](/it/manuals/recording) da Lua o dagli strumenti di sviluppo.
