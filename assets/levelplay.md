description: Official Defold native extension for Unity LevelPlay, an ad mediation and monetization platform for Android and iOS. It exposes an object-based Lua API for rewarded, interstitial and banner ads, supports multiple ad units, and provides configurable adapters for networks including Unity Ads, Google AdMob, AppLovin, Meta Audience Network, Pangle and Mintegral. LevelPlay combines real-time bidding and waterfall mediation with reporting, A/B testing and revenue-optimization tools. Version 2.0.0 replaces the legacy ironSource API with Unity LevelPlay SDK 9 and requires existing integrations to migrate to the levelplay namespace and [levelplay] configuration. Learn more about LevelPlay at https://unity.com/products/levelplay.
