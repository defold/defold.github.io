description: "A Native Extension for HTML5 games in Defold for access and operations on the browser's clipboard and file APIs. Copy and paste clipboard content, open files through system dialogs, save or download data, and accept files via desktop drag-and-drop. Operations return results through asynchronous Lua callbacks. Supports modern desktop and mobile browsers with fallbacks for mobile devices. Clipboard access is subject to browser permissions."
