title: SpriteLoop
description: SpriteLoop is a lightweight 2D cut-out animation tool for rigging characters, props, UI elements, and effects from separate PNG parts. Build parent-child rigs, animate transforms and opacity, reuse animations across skins and part variants, and export compact .spla runtime packages. The Defold extension adds SpriteLoop as a custom game object component with editor integration. Add a SpriteLoop component, assign an exported .spla package, choose its default skin, and control playback from Lua. The runtime also supports animation events, skin and part-variant switching, tinting, seeking, and querying animated part transforms for attachments and gameplay logic.
