# Développement pour Nintendo Switch {#nintendo-switch-development}

En raison des restrictions de licence de Nintendo, l'accès aux versions de Defold prenant en charge la plateforme Nintendo Switch n'est pas inclus dans la version standard de Defold. Pour accéder aux versions de Defold prenant en charge Nintendo Switch, vous devez devenir un développeur de jeux agréé pour Nintendo Switch.


## S'inscrire en tant que développeur Nintendo Switch {#registering-as-a-nintendo-switch-developer}

Vous pouvez vous inscrire en tant que développeur de jeux pour Nintendo Switch sur le [portail des développeurs Nintendo](https://developer.nintendo.com/register) :

![](/manuals/images/nintendo-switch/register-nintendo.png)

Une fois votre inscription approuvée par Nintendo, vous aurez accès à la page Tools and Middleware du portail des développeurs Nintendo, où vous pourrez demander l'accès à Defold. Lorsque vous demanderez l'accès à Defold, nous recevrons un e-mail de Nintendo confirmant votre statut de développeur Nintendo enregistré.


## Accès à Nintendo Switch dans Defold {#nintendo-switch-access-in-defold}

Une fois votre statut de développeur Nintendo Switch agréé confirmé, nous vous donnerons accès aux éléments suivants :

* Accès au code source de l'extension Nintendo Switch, avec les intégrations d'API propres à la console.
* Accès au code source de la version du moteur de jeu Defold prenant en charge Nintendo Switch. Notez que l'accès au code source n'est pas nécessaire pour créer des jeux pour Nintendo Switch, mais que nous le fournissons si vous souhaitez contribuer au code source du cœur du moteur.
* [Outil en ligne de commande](/fr/manuals/bob) permettant de créer des bundles pour la plateforme Nintendo Switch. La création de bundles depuis l'éditeur Defold n'est pas prise en charge.
* Forum où vous pouvez obtenir une assistance propre à Nintendo Switch.
