## Defold now supports Microsoft Xbox

![Defold adds support for Microsoft Xbox](/images/posts/newsletters/2026-october/xbox.webp)

Microsoft Xbox support is available from **Defold 1.14.0**, free of charge for approved Xbox developers. This brings Defold to all three major console platform families: Xbox, PlayStation, and Nintendo Switch.

To get started, your organisation must first be approved by Microsoft for Xbox console development. You can then request access to Defold through the Xbox middleware page. The announcement explains the process and links to the setup instructions.

[Read the Xbox announcement](https://defold.com/2026/10/12/Defold-adds-support-for-Microsoft-Xbox/)

## Minit Games joins the Defold Foundation

![Minit Games partners with the Defold Foundation](/images/posts/newsletters/2026-october/minit_partnership.webp)

Welcome to our new **Bronze Partner, Minit Games**! The platform is built around instant-play micro web games: short, portrait-oriented experiences that players discover by scrolling through a feed.

Defold's small HTML5 builds and fast loading times are a natural fit for this format. Developers can already explore the Minit SDK, a project template, and an example game. Together with Minit Games, we will also organise game jams with cash prizes.

[Read the Minit Games announcement](https://defold.com/2026/10/08/Minit-Games-joins-the-Defold-Foundation/)


## Community events

![Hacktoberfest 2026](/images/posts/newsletters/2026-october/community_events.webp)

There are several ways to get involved with the Defold community this autumn: contribute during **Hacktoberfest**, then make games for the **Pixel Forge MEGA Jam** and **Cosmo Hacks**, both supported by Defold.

- [Hacktoberfest 2026](https://forum.defold.com/t/hacktoberfest-2026-celebration/83325): join the community celebration and contribute to Defold projects.
- [Pixel Forge MEGA Jam](https://itch.io/jam/pixel-forge-mega-jam): a 10-day game jam with prizes, including rewards for the best games made with Defold.
- [Cosmo Hacks](https://cosmohacks.devpost.com/): an online hackathon with prizes and opportunities to build and share your project.

Visit each event page for its schedule, rules, and participation details.

## [Defold 1.14.0 has been released](https://defold.com/2026/10/12/Defold-1-14-0/)

![Defold 1.14.0 has been released](/images/posts/newsletters/2026-october/defold_1_14_0.webp)

Defold 1.14.0 expands console support and brings new rendering tools, mobile improvements, and a more efficient editor.

Highlights:

- 🎮 Microsoft Xbox support for approved developers
- 🧊 Cubemap render targets for custom reflections and environment capture
- 📱 iOS 27 support and improved safe-area handling, ready for iPhone Duo
- 💪 Support for up to 1,048,576 game objects per collection
- 🌍 Improved editor text shaping for complex scripts, emojis, and bidirectional text
- 🍎 Metal as the default graphics backend on macOS
- 🛠️ Configurable editor tab shortcuts and a redesigned Material Editor
- ⚡ Reduced editor CPU usage, plus more improvements and fixes!

The release also includes breaking changes. Check the release announcement for the migration details before upgrading an existing project.

[CHECK THE RELEASE ANNOUNCEMENT](https://defold.com/2026/10/12/Defold-1-14-0/)
